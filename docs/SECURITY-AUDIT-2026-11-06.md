# Dependency security audit — 6 November 2026

Tooling: Node 22.23.4, npm 10.9.9. Method: `npm audit` before and after, compatible fixes only (no `npm audit fix --force`).

| | Critical | High | Moderate | Total |
|---|---|---|---|---|

| After (all dependencies)  | 0 | 1 | 10 | 11 |

## Resolved
- `dompurify` (critical), `proxy-addr` (critical), `body-parser` (high) and 24 related transitive findings — fixed by compatible updates in `package-lock.json` (`npm audit fix`, no manifest majors).
- `nodemailer` (high, direct, `artifacts/api-server`) — upgraded `^9.0.1` → `^10.3.1`. It is used only through `createTransport`/`sendMail` in `publish-pipeline.ts` and `website-intelligence/notify.ts`. API-server typecheck is identical before and after.

## Accepted exception (documented, not hidden)
- `zod` 3.25.x (high, direct; production) — advisory: memory exhaustion when validating oversized constrained collections; fixed only in zod ≥ 4.6.7, a major version. Zod 3 is used by the frontend forms, `@workspace/api-zod` (generated by orval), `drizzle-zod` and `openai`. Upgrading all of them together is a migration, not a patch.
  Mitigation until then: do not validate unbounded client-supplied arrays with zod without a length cap; request body size limits stay on at the API layer.
  Next action: migrate to zod 4 (the 3.25 line already ships `zod/v4`), regenerate `api-zod`, run the full test suite.

## Outstanding (development tooling only — not shipped in the production bundle)
- `esbuild` ≤ 0.24.2 via `@esbuild-kit/*` via `drizzle-kit` 0.31.11 (moderate). The deprecated `@esbuild-kit` packages come only from `drizzle-kit`; 0.31.11 is the latest release and still depends on them, so they cannot be swapped for `tsx` without dropping drizzle-kit. Affects the local dev server only.
- `orval` → `typedoc` → `minimatch`, `typedoc-plugin-markdown` (moderate), `@tailwindcss/typography` → `postcss-selector-parser` (moderate): build-time tools processing trusted repository files.
- `recharts` 2.15.4 deprecation notice: not a vulnerability. Upgrading to v3 changes component APIs; deferred to avoid breaking existing charts.

## Guard rails added
